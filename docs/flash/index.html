Install Ivee on your device

For the Waveshare ESP32-S3-Touch-AMOLED-2.16. Set up the Ivee server first: you'll need its address.

  1. Plug the device into this computer with a USB-C data cable. Use Chrome or Edge on a desktop computer. When the browser lists ports, pick the one called USB JTAG/serial debug unit. This browser can't flash devices. Open this page in Chrome or Edge on a desktop computer. Flashing needs a secure page (https).

    Choose the device's serial port, then Install. Say yes to erasing the device on a first install. It takes about two minutes.

  2. The device restarts and opens a Wi-Fi hotspot called Ivee-XXXX. Join it from your phone or computer; the setup page opens (if not, go to http://192.168.4.1).
  3. Pick your home Wi-Fi, enter its password and press Connect. The device joins your Wi-Fi and finds your Ivee server by itself (the server announces itself as ivee.local). Say "Speel" to start talking.
  4. Only if the screen shows a connection error: unplug the device, plug it back in and press its BOOT button within 3 seconds to reopen the setup hotspot. On the Advanced tab, set Custom OTA URL to the address on your server's config page and press that tab's Save. Wait for "Configuration saved" before going back to the Wi-Fi tab.

    http://<server-ip>:8003/xiaozhi/ota/

    Some networks (guest Wi-Fi, some mesh routers) block the .local names the device uses to find the server.

Prefer the command line? Download ivee-merged.bin from the latest release and run esptool.py --chip esp32s3 write_flash 0x0 ivee-merged.bin.
